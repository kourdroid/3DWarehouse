## 2026-05-31 - Text-Symbol Button Accessibility\n**Learning:** Buttons using text-symbols (like '✕') as icons need explicit `aria-label` and `title` attributes. Without them, screen readers may read the symbol aloud unnecessarily or poorly, and mouse users lack clear context.\n**Action:** Always pair `aria-label` (for screen readers) and `title` (for mouse users) on icon-only buttons using text-symbols.
